# Tabuleiro de Xadrez
Projeto acadêmico desenvolvido na disciplina de Desenvolvimento de Sistemas Distribuídos, do curso de Análise e Desenvolvimento de Sistemas (IFRN) que consiste em um jogo de xadrez simples no navegador. O principal objetivo desse projeto era utilizar e aprender na prática os conceitos de WebSocket e comunicação simultânea em tempo real

## O que o projeto possui
- **Servidor WebSocket feito na linguagem C# utilizando a biblioteca ```System.Net.WebSocket```**
- **Cliente web e lógica de jogo feitos na linguagem Javascript utilizando a linguagem de marcação HTML para exibição da página web**
